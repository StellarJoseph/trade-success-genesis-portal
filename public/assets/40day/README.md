40-Day Challenge image assets

This folder contains lightweight SVG placeholders used during development. Replace them with licensed artwork from Envato Elements or Freepik before production.

Recommended asset guidance

1) Hero / Lead Visual
   - Suggested keywords: "AI trading dashboard", "crypto analytics hero", "futuristic finance illustration"
   - Envato Elements example search: https://elements.envato.com/search/ai%20trading%20dashboard
   - Freepik example search: https://www.freepik.com/search?format=search&query=ai%20trading
   - Recommended asset types: high-resolution illustration, abstract analytics hero, or lifestyle photo showing trading activity.
   - Place the licensed file as: public/assets/40day/hero.jpg (or webp)

2) Dashboard screenshot / UI preview
   - Suggested keywords: "dashboard UI", "analytics dashboard crypto", "trading UI mockup"
   - Place as: public/assets/40day/dashboard.jpg

3) Community / Support imagery
   - Suggested keywords: "community", "team chat", "mentorship", "online group"
   - Place as: public/assets/40day/community.jpg

Notes
- Use only properly licensed assets. Keep licenses and attribution records in your project documentation.
- Prefer modern formats (webp) for faster load and better quality.
- After adding real assets, remove or update the captions in the page component that point to Unsplash placeholders.
